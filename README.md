# 资产看板

**在线使用：<https://qimingren51.github.io/test_project/>**

手动记录、数据只存在本机的个人资产看板。iOS 风格，主要为手机设计，可以添加到主屏幕当 App 用。纯静态网页，无需构建。

- **总览**：总资产（统一以人民币计）、本金、累计收益；趋势图（1 月 / 3 月 / 6 月 / 1 年 / 全部，按住拖动查看某一天）；资产配置（按类型 / 按平台 / 按币种，可展开看子类和具体机构）；月度变化。
- **账户**：按「机构大类 → 具体机构 → 账户」或按资产类型分组；新增、编辑、删除账户和单条记录；一键盘点，可同时记录存入和取出。
- **分类**：资产类型（现金·存款、股票、基金、理财产品、黄金·商品、养老·保险、其他）带子类；机构分为支付方式、银行、券商、基金与理财，预设了常见的国内外银行和券商，也可以自定义。
- **多币种**：账户可以是人民币、英镑或美元，按你在设置里填的汇率折算进总资产。
- **设置**：个人资料、外观（自动 / 浅色 / 深色）、涨跌配色、汇率、隐藏金额、待更新提醒、导出 JSON / CSV 备份、导入备份。

账户为空时会展示示例数据（页面顶部有提示），添加第一个账户后自动切换为你自己的数据。

### 添加到手机主屏幕

- iPhone：用 Safari 打开上面的链接，点分享按钮，选「添加到主屏幕」。
- 安卓：用 Chrome 打开，点右上角菜单，选「添加到主屏幕」或「安装应用」。

## 数据与隐私

所有数据保存在当前浏览器的 localStorage 里，不会上传到任何服务器，也没有任何统计或追踪。清除浏览器数据或更换设备会丢失数据，请在「设置」里定期导出备份（用了两周以上还没备份时，页面会提醒）。

## 本地运行

```sh
python3 -m http.server 8000
```

然后打开 <http://localhost:8000>。因为使用了 ES modules，不能直接双击 `index.html` 用 `file://` 打开。

## 部署到 GitHub Pages

仓库 Settings → Pages → Source 选 "Deploy from a branch"，选择 `main` 分支和 `/ (root)`，保存即可。推送到 `main` 后一两分钟自动更新。

代码结构和开发约定见 [CLAUDE.md](CLAUDE.md)。
