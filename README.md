# 资产看板

手动记录、数据只存在本机的个人资产看板。纯静态网页，无需构建，可直接部署到 GitHub Pages。

- **总览**：总资产、本金、累计收益，趋势图（可按 1 月 / 3 月 / 6 月 / 1 年 / 全部查看），资产配置，月度变化。
- **账户**：按平台分组的账户列表，新增、编辑、删除，一键盘点。
- **设置**：涨跌配色（红涨绿跌 / 绿涨红跌）、导出 JSON / CSV 备份、导入备份。
- 支持深色模式和隐藏金额，可添加到手机主屏幕。

账户为空时会展示示例数据（页面顶部有提示），添加第一个账户后自动切换为你自己的数据。

## 数据与隐私

所有数据保存在当前浏览器的 localStorage 里，不会上传到任何服务器。清除浏览器数据或更换设备会丢失数据，请在「设置」里定期导出备份。

## 本地运行

```sh
python3 -m http.server 8000
```

然后打开 <http://localhost:8000>。因为使用了 ES modules，不能直接双击 `index.html` 用 `file://` 打开。

## 部署到 GitHub Pages

仓库 Settings → Pages → Source 选 "Deploy from a branch"，选择分支和 `/ (root)`，保存即可。

代码结构和开发约定见 [CLAUDE.md](CLAUDE.md)。
